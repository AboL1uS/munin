# Munin 🦅

> **Munin** — персональный трекер обучения, интерактивные дорожные карты (Roadmaps), таймер глубокого фокуса (Pomodoro) и стрик-календарь активности.

---

## 🚀 Возможности

- 🗺️ **Интерактивные дорожные карты**: создание, редактирование и отслеживание веток обучения (Java, JavaScript, Python и любые пользовательские темы).
- ⏱️ **Таймер фокуса (Pomodoro)**: настраиваемые интервалы работы и перерывов со звуковым сигналом (Web Audio API).
- 🟩 **Стрик-календарь активности**: наглядная сетка в стиле GitHub с отслеживанием серий дней подряд.
- 🎨 **5 цветовых тем**: Dark, Light, Rose, Navy, Beige.
- ⚡ **Быстрый поиск (Command Palette)**: мгновенная навигация по сочетанию клавиш `Ctrl + K`.
- 💾 **Полная автономность**: сохранение данных в браузере, экспорт и импорт резервных копий в JSON.

---

## 🛠️ Запуск в режиме разработки

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

---

## 📦 Сборка Windows приложения (.exe) локально

```bash
# Собрать автономный портативный .exe и инсталлятор
npm run build:exe
```
Готовые файлы появятся в папке `release/`:
- `Munin-1.0.0-win-portable.exe` — запуск без установки
- `Munin-1.0.0-win-nsis.exe` — мастер установки с созданием ярлыка

## 🌐 Автоматическая публикация релизов на GitHub (GitHub Releases)

В репозитории настроен GitHub Actions Workflow (`.github/workflows/release.yml`).

### Способ 1. Через создание тега (Git)
```bash
git tag v1.0.0
git push origin v1.0.0
```

### Способ 2. В интерфейсе GitHub
1. Перейдите во вкладку **Actions** в вашем репозитории.
2. Выберите workflow **Release Munin**.
3. Нажмите кнопку **Run workflow**.

GitHub автоматически запустит виртуальную машину Windows, выполнит чистую сборку и прикрепит готовые `.exe` файлы к разделу **Releases**!
